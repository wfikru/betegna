1. Relational Database Schema & ERD Architecture

USERS Module 1

ESCROW_TRANSACTIONS Module 4

DISPUTES & ARBITRATION Module 5

evidence_urls TEXT[] S3 PHOTOS
status VARCHAR(32) 'open'/'resolved'
admin_user_id UUID FK -> users

2. Finite State Machine (7-State Job Lifecycle)

1. DRAFT
Scoping complete; rate & total calculated
→
2. REQUESTED
Stripe Card Auth Hold (100% + 15% margin)
→
3. ACCEPTED
Time slot locked; Twilio VoIP chat active
→
4. EN ROUTE
FCM/APNS Push: "Tasker is on the way!"
→
5. IN PROGRESS
Tasker on-site; GPS Geofence confirmed
→
6. COMPLETED
After photo uploaded; Client sign-off pending
→
7. PAID
Stripe capture; 18% fee; 82% direct deposit

3. Escrow & Split-Payment Payout Architecture

Gross Customer Authorization Hold
1,000.00 ETB
Stripe manual PaymentIntent authorization hold placed on card at booking time
Platform Service Fee (18%)
180.00 ETB
Automated deduction to Betegna Stripe platform account for insurance, support, & KYC
Tasker Net Earnings Payout (82%)
820.00 ETB
Automated transfer to Tasker's Stripe Connect Express account (ACH Direct Deposit)

4. Critical User Stories Across All Modules

ID Persona User Story Acceptance Criteria (Technical & Gherkin)
US-1.1 Customer Sign up & save default card securely via Stripe SetupIntent Given an unauthenticated visitor, When they complete SMS OTP and add a card via Stripe PaymentSheet, Then a Stripe Customer is created without sensitive PAN data touching app servers.
US-1.2 Tasker Multi-step KYC identity verification & Checkr background check Given a Tasker completing onboarding, When they submit ID and selfie via Stripe Identity, Then automated webhook confirms match score >= 95% and triggers Checkr criminal check.
US-1.3 Tasker Configure spatial geofenced operating radius & hourly rates Given an active Tasker, When they define a 15 km radius around Addis Ababa coordinates and set Repairs rate to 450 ETB/hr, Then PostGIS spatial index excludes jobs outside the polygon.
US-2.1 Client Dynamic scoping questionnaire for accurate price estimation Given Client selecting "Cleaning", When they answer rooms=3, bathrooms=2, bring_supplies=true, Then scoping engine calculates 4.0h estimated duration and adds supply surcharge.
US-2.2 Client Real-time spatial & availability matching ranked by algorithm Given job coordinates and start=Tomorrow 09:00, When search executes, Then PostGIS/Redis query returns available Taskers sorted by distance, response rate, and rating score.
US-3.1 Tasker & Client Masked VoIP calling and photo evidence in WebSockets chat Given an accepted booking, When user taps Call/Message, Then Twilio Proxy masks phone numbers; photos uploaded to S3 extract EXIF GPS coordinates for evidence records.
US-4.1 Client Escrow authorization hold until digital completion sign-off Given an estimated 1,000 ETB job, When booking submits, Then Stripe PaymentIntent places manual hold; funds are only captured when job reaches 'completed' state.
US-4.2 Tasker Automated 18% split-payment platform fee & 82% ACH payout Given a completed job, When Client signs off, Then Stripe captures 1,000 ETB, deducts 180 ETB fee, and transfers 820 ETB net to Tasker Connect account.
US-5.1 Tasker & Client Double-blind review system preventing retaliatory ratings Given a paid job, When Client submits a 3-star review, Then review is hidden until Tasker also reviews OR 14 days elapse, preventing retaliation.
US-5.2 Support Admin Internal dispute dashboard with chat logs & EXIF photo inspector Given an open dispute ticket, When Admin reviews EXIF GPS coordinates proving Tasker short-hours and executes REFUND_PARTIAL(50%), Then Stripe splits refund/payout accordingly.
