## 4. Implementation notes
- Each "add now" category ships as a taxonomy entry + 2–4 services with configuration-driven questionnaires (same pattern as the existing 33).
- The home type-ahead search, NL parser synonyms, and pro onboarding all pick new categories up automatically — only seed data changes.
- Recommended phasing: 3 categories/week so demo supply (professionals) can be seeded per category to avoid empty results.
